# 发送邮件

## 何时使用

用户要求发送邮件、发信、把内容通知到某个邮箱或某个称呼时使用本 Skill。

## 如何调用

先确认收件人，再执行（to / subject / body 必须作为独立参数传入，不要放进嵌套对象）：

```text
run_skill(name="email", to="雨帆", subject="主题", body="正文")
run_skill(name="email", to="一言不合看我炸毛", subject="调休通知", body="我明天调休一天，去上海旅游")
```

`to` 用系统提示或本说明书里列出的通讯录称呼。不要自己判断谁在不在通讯录，必须调用脚本，由脚本校验。禁止编造邮箱、禁止发到通讯录以外的地址。系统会在发送前要求用户确认。

## 参数

- `to`：收件人邮箱，或通讯录称呼。
- `subject`：邮件主题。用户说了就用原话；没说则用一句简短概括。
- `body`：邮件正文。用户说了要传达的内容就写进去。

## 约束

- 必须使用脚本返回的发送结果。只有返回里出现 `#EMAIL_SENT` 才能告诉用户已经发出；禁止假装发送成功。
- 同一会话里，相同收件人 + 主题 + 正文只投递一次。断点续跑若发现已经发出，会跳过 SMTP，避免重复邮件。
- 收件人由脚本按通讯录白名单校验；未登记地址会被拒绝。历史对话里的「不在通讯录」可能是误判，以脚本返回为准。
- 收件人不明确时，先向用户询问要用哪个通讯录称呼，不要猜测，不要再 load_skill。
- 脚本报错时，把错误原因如实告诉用户，不要用相同参数重试。
- 不要把 SMTP 账号、授权码写进对用户的回复。
