# 天气查询

## 何时使用

用户询问某地当前或明天的天气、气温、降雨、湿度、风力，或做出行/穿衣相关天气判断时使用本 Skill。

## 如何调用

先确认城市名，再执行（city 必须作为独立参数传入，不要放进嵌套对象）：

```text
run_skill(name="weather", city="北京")
run_skill(name="weather", city="上海", when="明天")
```

`city` 支持中文或英文。用户说「明天」「明日」时，必须传 `when="明天"`，不要只查今天。
`上海`、`上海市`、`Shanghai` 视为同一地点，不要换一种写法再查一次。

判断冷暖或是否高于某温度时，优先看返回的「最高气温」或「气温」数字，不要自己编数字。

## 约束

- 必须使用脚本返回的实况或预报，禁止编造气温、天气或风力。
- 城市不明确时，先向用户询问要查哪个城市，不要猜测，不要再 load_skill。
- 脚本报错时，把错误原因如实告诉用户，不要用相同参数重试。
